# 🔧 iPhone Diagnostics AI - Android v1.1.0

تطبيق Android احترافي ومتكامل لتحليل مشاكل iPhone باستخدام AI

## ✨ المميزات (10+ ميزة)

### 📊 تحليل السجلات
- استيراد `.ips` `.txt` `.crash` `.log`
- تحليل AI للأخطاء
- عرض السجل الخام

### 📷 ماسح البورد
- CameraX للتصوير
- OCR للتعرف على أرقام القطع
- تحليل AI للمكونات
- دعم 4 مزودي OCR

### 🤖 مساعد AI محادثة
- إجابات ذكية لأسئلة الصيانة
- قاعدة معرفة شاملة
- اقتراحات سريعة

### 📚 قاعدة بيانات المكونات
- 8+ مكونات iPhone
- أرقام القطع والبدائل
- الأعطال الشائعة
- مستوى الصعوبة والسعر

### 📖 دليل الإصلاح التفاعلي
- خطوات مصورة
- تحذيرات وأدوات
- تقدم الخطوات

### 📋 تتبع التصليحات
- سجل العملاء
- حالة التصليح
- الإحصائيات والإيرادات

### 📄 تقرير PDF
- تقرير احترافي
- قابل للطباعة/المشاركة

### 🔧 اختبار API
- اختبار Backend
- اختبار OCR
- نتائج فورية

### ⚙️ إعدادات مرنة
- 4 مزودي OCR
- API Keys يدوية
- ML Kit مجاني

## 🚀 التشغيل

```bash
# Backend
cd Backend && python app.py

# Android
# افتح في Android Studio → Run
```

